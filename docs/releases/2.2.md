# MySubmissions 2.2

The first public release of MySubmissions is 2.2.2 (November 2026). Version 2 is the line in production use; version 1 was never public. These notes say what version 2.2 does, so a new organization knows what it is getting; later releases list only what changed.

## What the app does

**Submitting.** From a phone or a browser, staff pick Expense, Bank deposit or Income, fill in a short form, attach the documents (a photo of a receipt, an invoice PDF) and press Submit. Their open items stay listed under "Your items" until they are approved.

**Approving.** Approvers see two screens, Financial Approvals (expenses, reimbursements and deposits) and Income Approvals. Each item shows its details and attachments; the approver can fix the project or cost account, add a comment, and tick Approved. The app checks group membership, so only the people in the two approver groups see these screens.

**Sending to the bookkeeper.** One button, Send to bookkeeper, on Financial Approvals. It says how many approved items are waiting and their total, and on Send it starts the weekly flow. The flow puts a dated folder on the output site with every document, named by item number and amount, fills in a spreadsheet with one row per item (vendor, type, amount, project, cost account, links to each file), shares the folder with the bookkeepers, and emails the recipients with the item count and the links. Items are then marked processed. A second send on the same day adds to the same folder and workbook.

**Payment reminders.**
- A list on the lists site, **Payment Reminders**, holds one row per card or bill that is due on the same day each month: what it is, the day of the month it is due, a link to pay it, a note, and whether it is active.
- The weekly email gets a "Payment reminders" section listing anything due within the next 14 days, with the date, how many days away it is, and the link. For example: "Credit card: due Thursday 18 December (in 11 days). Pay at https://example.com/pay."
- The same reminders go in the week's workbook as rows after the items, with Type "Reminder", the due date and note in the Comment column and the link in LinkToThing. They have no item number and no amount, so they cannot be mistaken for a transaction. If you import the workbook into your bookkeeping software, skip rows of that type.
- Nothing appears when no payment is due soon. To add, change or pause a reminder, edit the row in SharePoint. Nobody needs to touch the app or the flow.

**Test mode.** While it is on, the folder name ends in TEST, nothing is marked processed, and only the finance director gets the email. Switch it off when the install checks out.

## Settings an organization chooses

| Setting | Default |
|---|---|
| How far ahead a reminder shows (`weekly.reminderDaysAhead`) | 14 days |
| Who gets the weekly email, who the folder is shared with, who gets test runs (`weekly.recipients`, `bookkeepers`, `financeDirector`) | you fill these in |
| Header colour and app icon (`brand`) | a green header, a plain icon |

Everything else is in `docs/SETTINGS.md`.

## For whoever installs it

- All four lists, the output library and the workbook template are made by `tools/setup_lists.py`. The reminders' due day runs 1 to 28, so every month has the date.
- The flow only runs when someone presses Send, roughly once a week, so the 14-day look-ahead is what makes sure a reminder lands in a send at least a week before the due date. Shorten it only if sends are more frequent.
- The package carries the weekly flow. In Import setup, set the flow's row to Update and pick the existing flow. Every import switches the flow off: turn it on again in Power Automate > My flows.
